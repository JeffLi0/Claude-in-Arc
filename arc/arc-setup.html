Claude in Arc would like to keep itself up to date

Arc can’t update extensions loaded with Load unpacked, so this one will:

Download each new release from GitHub
Write it into the Claude-in-Arc folder you loaded
Switch over only while you’re away and Claude isn’t working
!

After you click the button, a folder window opens. Choose the Claude-in-Arc folder you loaded in arc://extensions, then click Select.

Arc only lets an extension write to a folder you pick.
